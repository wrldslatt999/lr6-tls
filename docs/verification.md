# Протокол перевірки

Перевірка виконана в локальному Linux-середовищі підготовки проєкту (не в Kali студента). Сертифікати й користувачі для інтеграційних тестів генерувалися у випадковій тимчасовій директорії та не включені в репозиторій.

```bash
python3 -m unittest discover -s tests -v
```

Результат першого повного прогону: **22 tests, OK**. Тестові сценарії включають реальне TLS-з'єднання (не mock), перевірку CA та hostname, автентифікацію і відмову, бінарний payload, правильний і неправильний HMAC, повтор, rate limit, неправильний формат JSON, відмову від plain HTTP на TLS-порту, перевірку журналів без витоку тестового пароля.

Окрему перевірку в Kali слід додати до звіту після виконання команд із README і бажано окремим комітом.

## Повторна незалежна локальна демонстрація

Окремо від unittest виконано генерацію тимчасового CA, запуск `TLSServer`, підключення `client.exchange` та три реальні запити. Отримано `TLSv1.3`, cipher `TLS_AES_256_GCM_SHA384`, успішну передачу 30 байтів, відмову `bad_hmac` і `invalid_credentials`. Усі фактичні параметри зафіксовано в [`reports/smoke-test.json`](../reports/smoke-test.json). Це **результат в окремому локальному Linux-контейнері**, не в середовищі Kali користувача.
